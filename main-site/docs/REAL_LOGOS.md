# Real team & league badges — rights and attribution

v9 maps **111 teams** and **6 competitions** to image URLs supplied by the already-connected football-data.org fixture cache. The browser displays remote images; this repository does not embed image binaries or copy logos into Cloudflare storage. Team/league assets are rendered in match listings and dialogs, with a local placeholder on HTTP/image failures.

**Rights warning:** Under football-data.org [Terms §9.2](https://www.football-data.org/client/register), these graphics remain copyrighted by their respective owners and permission for use on a website is the website operator's responsibility. The availability of an image URL in an API is **not proof of a display license**. The owner should secure authorization or replace individual images with properly licensed alternatives if required. This implementation is a technical integration and does not grant license rights.

Only six competitions from existing provider cache have mapped emblems. Other leagues retain a fallback until an image can be matched, checked and authorized. Model outputs and predictions are unchanged.
